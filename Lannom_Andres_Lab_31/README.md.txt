# Student Grade Calculator

## Description
The Student Grade Calculator is a C++ program that allows users to enter three exam scores and calculate their average. The program converts the average into a letter grade (A, B, C, D, or F). It also validates the scores to make sure they are between 0 and 100.

## How to Run
1. Open the project folder in Visual Studio.
2. Open the C++ project or solution file.
3. Press Ctrl + F5 to build and run the program.
4. Enter three numerical exam scores when prompted.
5. View the calculated average and corresponding letter grade.

## Sample Input / Output

**Input:**
- Score 1: 90
- Score 2: 85
- Score 3: 75

**Output:**
- Average: 83.33
- Grade: B
