# Student Grade Calculator — Lab 3

## Description
The Student Grade Calculator is a C++ program that calculates a student's average from three exam scores. It converts the numerical average into a letter grade (A, B, C, D, or F). The program also checks for invalid inputs to ensure scores are between 0 and 100.

## How to Run
1. Download or clone the GitHub repository.
2. Open the `Lannom_Andres_Lab_31.sln` file in Visual Studio.
3. Press Ctrl + F5 to compile and run the program.
4. Enter three exam scores between 0 and 100.
5. View the numerical average and corresponding letter grade.

## Sample Input
- Score 1: 90
- Score 2: 85
- Score 3: 75

## Sample Output
- Average: 83.33
- Grade: B
